# Transcribe Worker Agent

Distributed Python asynchronous inference agent for the Transcribe platform.

## Features

- **Asynchronous WebSocket signaling**: Persistent connection to central controller with heartbeat and auto-reconnect.
- **Hardware monitoring**: Non-blocking host CPU/RAM utilization telemetry via `psutil` with safe fallback for GPU/CUDA.
- **Concurrency & GIL protection**: Controlled concurrency with `asyncio.Semaphore` and threadpool executor offloading for CPU-heavy / blocking inference tasks.
- **Global exception shielding**: Any task failure is reported to the controller (`status="failed"`) without terminating the agent process.
- **OpenAI-compatible format**: ASR engines output OpenAI `verbose_json` compliant responses.
- **Mock ASR Engine**: Multi-stage progress simulation (20%, 50%, 80%, 100%) for testing and lightweight deployments.

## Quick Start

### Installation

Requires Python 3.12+ and `uv`:

```bash
uv sync
```

### Configuration

Configuration is loaded from `config.yaml` or overridden by environment variables:

- `CONTROLLER_URL`: URL of the controller service (default: `http://localhost:8080`)
- `AGENT_TOKEN`: Authentication token generated by the controller
- `NODE_NAME`: Node identifier (default: `agent-default`)
- `HEARTBEAT_INTERVAL`: Interval in seconds between heartbeats (default: `10`)
- `MEDIA_DIR`: Temporary media download directory (default: `/tmp/transcribe/media`)
- `MAX_CONCURRENT_JOBS`: Maximum concurrent transcription jobs (default: `2`)

### Running

#### Interactive Service Management (Recommended)

Use the interactive management script:

```bash
./agent.sh
```

Or pass commands directly:

```bash
./agent.sh start    # Start service in background
./agent.sh stop     # Stop running service
./agent.sh status   # Check status and recent logs
./agent.sh restart  # Restart service
```

#### Manual Run

```bash
uv run python main.py
```

### Running Tests

```bash
uv run pytest
```
